# Расшифровка полей расчета

Этот файл описывает поля, которые страница `/costs` добавляет к каждому объекту при скачивании расчета.

Исходные поля объявления не удаляются. Например, `title`, `price`, `adress`, `dop`, `description`, `url`, `Родина`, `работа Оли` и любые другие свойства остаются в объекте.

## Добавляемые поля

- `months` - количество месяцев, за которое считается аренда.
- `rent_per_month` - стоимость аренды за один месяц.
- `rent_for_period` - стоимость аренды за весь выбранный период: `rent_per_month * months`.
- `commission_percent` - процент комиссии агентства, найденный в описании или условиях.
- `commission` - сумма комиссии агентства: `rent_per_month * commission_percent / 100`.
- `deposit` - залог или депозит, найденный в описании или условиях.
- `total_for_period` - общая сумма к оплате за период: `rent_for_period + commission + deposit`.

## Пример

Если аренда `40 000 ₽/мес.`, срок `3` месяца, комиссия `50%`, залог `40 000 ₽`, то:

- `rent_for_period` = `40 000 * 3` = `120 000`
- `commission` = `40 000 * 50 / 100` = `20 000`
- `deposit` = `40 000`
- `total_for_period` = `120 000 + 20 000 + 40 000` = `180 000`
