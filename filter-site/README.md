# Фильтр объектов

Отдельный сайт для просмотра, фильтрации и экспорта JSON-файлов с объектами.

## Запуск

```bash
npm start
```

Чтобы открыть сайт на порту `3000` и сделать его доступным из локальной сети:

```bash
PORT=3000 HOST=0.0.0.0 npm start
```

По умолчанию сайт открывается на:

```text
http://localhost:3000
```

Если порт занят, сервер попробует следующие порты.

С другого устройства в той же сети открывай:

```text
http://<IP-адрес_этого_компьютера>:3000
```

## Страницы

- `/` - фильтр объектов.
- `/merge` - объединение двух JSON-файлов.

## Файлы

- `app.js` - сервер и интерфейс фильтра.
- `example-result.json` - пример файла с объектами для загрузки в фильтр.
