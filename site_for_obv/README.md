# Сайт объявлений

Проект хранит пользователей, сессии и объявления в локальной SQLite-базе.
У каждого пользователя свой список квартир.

## Запуск

Обычно проект запускается из корня общего портала:

```bash
cd C:\Users\0\Documents\api-map
npm start
```

После этого сайт объявлений доступен через общий сервер:

- `http://localhost:3000/analytics`
- `http://localhost:3000/login`
- `http://localhost:3000/register`

Для отдельной отладки только этого сервиса:

```bash
npm start
```

После запуска:

- главная страница: `http://localhost:3000`
- аналитика подбора: `http://localhost:3000/analytics`

Нужен Node.js 24 или новее, потому что используется встроенный модуль `node:sqlite`.

## Данные

- `data/app.sqlite` - SQLite-база, создается автоматически при старте.
- `uploads/<userId>/` - архив JSON-файлов, загруженных конкретным пользователем.

В базе создаются таблицы:

- `users` - пользователи.
- `sessions` - серверные сессии.
- `listing_meta` - метаданные списка пользователя.
- `listings` - квартиры пользователя.

Пароли не хранятся открытым текстом. В базе сохраняется хеш пароля и соль.

## Возможности

- регистрация и вход;
- загрузка JSON-массива объектов;
- режим замены списка или добавления к списку;
- просмотр только своих объектов;
- удаление одного объекта;
- очистка всего своего списка.

## API

- `POST /api/register` - регистрация.
- `POST /api/login` - вход.
- `POST /api/logout` - выход.
- `GET /api/me` - текущий пользователь.
- `GET /api/listings` - список объектов текущего пользователя.
- `POST /api/import?mode=replace|append` - загрузка объектов.
- `DELETE /api/listings/:id` - удалить один объект текущего пользователя.
- `DELETE /api/listings` - очистить список текущего пользователя.
