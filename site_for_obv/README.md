# Сайт объявлений

Проект хранит объявления в локальной JSON-базе и показывает их на главной странице.

## Запуск

```bash
npm start
```

После запуска:

- главная страница: `http://localhost:3000`
- панель управления: `http://localhost:3000/admin`

## Загрузка данных

В панели управления можно загрузить JSON-файл с объявлениями. Поддерживается массив объектов напрямую:

```json
[
  {
    "title": "2-к. квартира, 45 м²",
    "price": "50000 ₽ в месяц",
    "address": "Москва, улица Примерная, 1",
    "description": "Описание объекта",
    "url": "https://example.com/listing"
  }
]
```

Также можно загрузить объект с массивом в поле `items`, `listings`, `objects`, `data` или `apartments`.

## Файлы данных

- `data/listings.json` - текущая база объявлений.
- `uploads/` - архив загруженных JSON-файлов.
