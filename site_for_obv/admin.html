Загрузка объявлений

Добавьте квартиры в личную базу. Аналитика обновится автоматически и покажет только ваши объявления.

К аналитике

Импорт JSON

Поддерживается массив объявлений или объект с полем items, listings, objects, data или apartments.

Добавить одно объявление

Вставьте JSON одного объявления. Если такой id уже есть в вашей базе, дубль не сохранится.

Пример структуры файла

[
  {
    "id": "flat-1",
    "title": "2-к. квартира, 45 м²",
    "price": "50000 ₽ в месяц",
    "address": "Москва, улица Примерная, 1",
    "deposit": 50000,
    "commission": 25000,
    "utilities": 5000,
    "commuteWork": "45 мин",
    "commuteHome": "55 мин",
    "url": "https://example.com/listing"
  }
]
