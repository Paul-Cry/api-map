# Общий сервер

Единая точка входа для рабочих сайтов в проекте.

## Запуск

```bash
cd C:\Users\0\Documents\api-map
npm start
```

После запуска открой:

```text
http://localhost:3000
```

## Маршруты

- `/` - главная страница портала.
- `/feed` - лента объявлений.
- `/admin` - панель управления базой объявлений.
- `/login` - вход.
- `/register` - регистрация.
- `/worker` - панель управления Worker API.
- `/filter` - фильтр объявлений.
- `/merge` - объединение JSON-файлов из фильтра.

## Структура

- `portal-server.js` - общий сервер-роутер.
- `site_for_obv/` - сайт ленты объявлений и панели управления базой.
- `worker-api/` - API и панель управления worker.
- `filter-site/` - сайт фильтра объектов.
- `scripts/avito/`, `scripts/chian/`, `scripts/yandex-map/` - вспомогательные скрипты.
