# Avito Parser

Userscript для Tampermonkey, который автоматически запускается на Avito и собирает видимые карточки объявлений в массив `items`.

## Что делает

- Открывает две встроенные панели на самой странице Avito: действия справа и логи слева.
- Автоматически запускает сбор, как только открывается любая страница `avito.ru`.
- Складывает результаты в массив объектов `items`.
- Сохраняет данные в `result.json` через меню Tampermonkey или кнопку скачивания.

## Что сохраняется

Каждый элемент `items` содержит:

- `title`
- `price`
- `adress`
- `dop`
- `description`
- `url`

## Как использовать

1. Установи Tampermonkey.
2. Открой файл [`avito-tampermonkey.user.js`](/D:/Project/avito-tampermonkey.user.js).
3. Нажми `Install`.
4. Открой нужную страницу Avito.
5. Открой любую страницу Avito.
6. Скрипт стартует сам, а процесс будет виден в панели логов слева.

## Примечание

Если панель логов не появилась сразу, нажми `Показать окно логов` в панели скрипта.
